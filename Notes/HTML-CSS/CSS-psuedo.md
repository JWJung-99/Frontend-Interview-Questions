# CSS 의사 요소와 의사 클래스

<br />

## 💧의사 요소

의사 요소(pseudo-element)는 CSS 선택자에 추가하는 키워드로, 특정 요소의 **일부분에 스타일을 적용할 때 사용**합니다. 일반적인 CSS 선택자는 요소 전체의 스타일을 지정하지만, 의사 요소를 사용하면 요소 내부의 특정 부분에만 스타일을 적용할 수 있습니다.

의사 요소를 사용하기 위한 문법은 다음과 같습니다.
```css
선택자::의사요소이름 {
  속성: 속성값;
}
```

대표적인 CSS 의사 요소는 다음과 같습니다.

- `::first-letter`: 텍스트의 첫 글자만을 선택하며, 블록 타입 요소에만 사용할 수 있습니다.
- `::first-line`: 텍스트의 첫 라인만을 선택하며, 블록 타입 요소에만 사용할 수 있습니다.
- `::before`: 특정 요소의 내용(content) 바로 앞에 다른 요소를 삽입할 때 사용합니다.
- `::after`: 특정 요소의 내용(content) 바로 뒤에 다른 요소를 삽입할 때 사용합니다.
- `::selection`: 해당 요소에서 클릭이나 마우스 드래그처럼 사용자에 의해 하이라이트된 부분에 스타일을 적용하기 위해 사용합니다.

<br />

## 🏫 의사 클래스

의사 클래스(pseudo-class)는 선택하고자 하는 HTML 요소의 **특별한 '상태(state)'를 명시할 때 사용**합니다. 의사 클래스는 요소의 상태나 조건을 기반으로 스타일을 변경한다는 점이 특징입니다.

의사 클래스를 사용하기 위한 문법은 다음과 같습니다.
```css
선택자:의사클래스이름 {
  속성: 속성값;
}
```

대표적인 CSS 의사 클래스는 다음과 같습니다.

- **동적 의사 클래스**
  - `:link`: `href` 속성을 가진 `<a>`, `<area>`, `<link>` 중 사용자가 아직 방문하지 않은 요소를 선택합니다.
  - `:visited`: 사용자가 방문한 적이 있는 링크를 선택합니다.
  - `:hover`: 사용자가 포인팅 장치를 사용해 상호작용 중인 요소를 선택합니다.
  - `:active`: 사용자가 활성화한 요소(버튼 등)를 나타냅니다.
  - `:focus`: 양식의 입력 칸 등 포커스를 받은 요소를 나타냅니다.

<br />

> [!NOTE]
> 
> 링크를 적절히 디자인하려면 LVHA-순서(`:link` — `:visited` — `:hover` — `:active`)를 따라 배치해야 링크의 상태에 따라 스타일을 충돌 없이 정확히 적용할 수 있습니다.

<br />

- **상태 의사 클래스**
  - `:checked`: 선택헀거나 `on` 상태일 라디오버튼, 체크박스, 옵션 요소를 나타냅니다.
  - `:enabled`: 모든 활성 요소(선택, 클릭, 입력 등 활성하거나 포커스를 받을 수 있는 요소)를 나타냅니다.
  - `:disabled`: 모든 비활성 요소를 나타냅니다.

- **구조 의사 클래스**
  - `:first-child`: 형제 요소 중 제일 첫 요소를 나타냅니다.
  - `:nth-child(<An+B> | even | odd)`: 형제 사이에서 순서에 따라 요소를 선택합니다.
  - `:first-of-type`: 형제 요소 중 자신의 유형과 일치하는 제일 첫 요소를 나타냅니다.
  - `:nth-of-type(<An+B> | even | odd)`: 형제 요소 중 자신과 유형이 일치하고 순서에 맞는 요소를 선택합니다.

- **기타 의사 클래스**
  - `:not(selector)`: 인수로 간단한 선택자를 취하며, 인수로 표시되지 않은 요소를 선택합니다.
  - `:lang(<language-code>)`: 특정 요소를 언어 설정에 따라 다르게 표현할 때 사용합니다.
