# Virtual DOM이란?

<br />

## 📲 Virtual DOM

Virtual DOM은 React에서 사용되는 핵심 개념으로, **실제 DOM을 JavaScript 객체 형태로 복제한 가벼운 사본**이라고 할 수 있습니다. 브라우저의 DOM은 구조적으로 복잡하고, 이를 직접 조작하는 작업은 성능 비용이 상당히 높기 때문에 Virtual DOM은 이를 개선하여 웹 애플리케이션의 성능을 최적화하기 위해 사용됩니다.

Virtual DOM의 핵심 아이디어는 상태 변경이 발생할 때마다 전체 UI를 Virtual DOM에 반영하고, 이를 **이전 상태와 비교해 필요한 부분에 한해 최소한의 DOM 업데이트를 수행**하는 것입니다. Virtual DOM 업데이트를 비교하는 일은 실제 DOM을 조작하지 않고 메모리 상에서 이루어지기 때문에 가볍고 빠르게 수행됩니다.

React에서 Virtual DOM을 활용하는 과정은 다음과 같습니다.

- **상태 변경**: 컴포넌트의 상태나 props가 변경되면 Virtual DOM이 다시 생성됩니다.
- **재조정(Reconciliation)**: 비교 알고리즘을 이용해 이전 Virtual DOM과의 차이를 계산합니다.
- **re-render**: 계산된 차이에 따라 실제 **DOM에서 필요한 부분만** 업데이트합니다.

## 🧮 React의 비교 알고리즘

React는 O(n<sup>3</sup>)의 복잡도를 가질 수 있는 트리 비교 문제를 휴리스틱 알고리즘을 이용해 O(n)으로 최적화했습니다.

### 1. 서로 다른 타입의 두 요소는 서로 다른 트리를 만들어냅니다.

DOM 요소의 **타입이 다르면**(ex. `<div>` → `<span>`) 비교를 수행하지 않고, **해당 요소와 자식을 모두 새로 생성**합니다. 자식 요소들의 내용이 같더라도 이전의 트리를 모두 버리고 완전히 새로 생성합니다. 이는 비효율적으로 보일 수 있지만 실제 애플리케이션에서 타입이 다른 경우는 완전히 다른 컴포넌트로 교체되는 상황이 많기 때문에 효율적입니다.

**동일한 타입의 요소라면, 동일한 내역은 유지하고 변경된 속성만 갱신**합니다.

```jsx
<div className="before" title="stuff" /></div>

// className만 수정
<div className="after" title="stuff" /></div>
```

<br />

### 2. 개발자가 `key` prop을 통해 여러 렌더링 사이에 어떤 자식 요소가 변경되지 않아야 할지 표시합니다.

같은 레벨의 자식들을 비교할 때 개발자가 입력한 `key` prop을 사용해 요소를 식별합니다. 이를 통해 리스트 내역의 일부가 수정되었을 때 모든 요소들을 갱신하지 않고 실제 변경된 요소만 감지하여 효율적으로 갱신합니다.
